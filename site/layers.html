DOT map layers

Browse NYC DOT's ArcGIS server (a841-dotweb01.nyc.gov): PRISM corners and ramps, the GAZETTEER (LION, AddressPoint, MapPLUTO and more) or any other folder. Pick a layer, filter it with a where clause or by distance from a point, and map or export the features.

Layers

PRISM and GAZETTEER are DOT's corner, ramp and street reference folders. Any other folder name on the server works too.

    Pick a layer to start

    Query
    For example CMTCornerID=1108794, or OnStreetName='7 AVENUE' AND BoroughCode=3. Text values take single quotes.
