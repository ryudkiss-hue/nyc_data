Make Safe SR brief

Public data for one NYC DOT Make Safe service request, or every SR on a workbook tab: PRISM corners and ramps, street permits, ramp program, ramp complaints, capital projects and nearby 311 requests. Everything runs in this browser; nothing you enter or upload leaves it except the queries to NYC Open Data and DOT ArcGIS.

About

This page is the browser version of nyc-opendata-mcp, a local MCP server for Claude Desktop and Claude Code that does the public-data side of the make-safe-batch procedure (SOP 20). Both use the same queries, filters and sort orders, and a parity test runs them on the same live SRs and compares the results.

Sources read live

  • DOT ArcGIS PRISM_CORNERS and PRISM_RAMPS: candidate corners, CMTCornerIDs, directions, BBL, ramps.
  • DOT ArcGIS GAZETTEER LION, AddressPoint and MapPLUTO: geocoding when an SR has no Lat/Lon, intersections PRISM names differently, the SR's own tax lot.
  • NYC Open Data tqtj-sjs8 Street Construction Permits, 97nd-ff3i Capital Reconstruction Projects (Intersection), e7gc-ub6z Pedestrian Ramp Program Progress, jagj-gttd Pedestrian Ramp Complaints, erm2-nwe9 311 Service Requests.

What it does not decide

The brief reports facts and names the rule each one feeds. Routing, the Make Safe type and the final corners rest on the street imagery and the caller's words, so they stay with the analyst. Street Smart, Dynamics and NYCStreets appear as links because they need a DOT sign-in.

Answers are cached in memory until the page is reloaded. A source that fails is listed under Errors with nothing filled in for it.
