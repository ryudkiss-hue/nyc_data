NYC DOT SIM · Open Data

Browser tools for the Sidewalk Inspection and Management unit. Everything reads NYC Open Data and DOT's ArcGIS server live, from this page; there is nothing to install and no server in between, and files you open stay in your browser.

Quick start

A dataset ID (jagj-gttd), a search term (sidewalk violations) or an SR number (311-29399735).

Explore data

Open any NYC Open Data dataset, filter it with a builder or plain SoQL, count by a column, profile its columns, map the rows and download CSV or JSON. Every query has a shareable link.

Datasets

The Sidewalk Program's datasets with live update dates against their freshness tier (HIGH 14, MEDIUM 30, LOW 60 days), row counts, joins and known issues.

DOT map layers

Browse PRISM corners and ramps, LION, AddressPoint, MapPLUTO and any other DOT ArcGIS layer. Query by attribute or distance from a point; map and export GeoJSON or CSV.

Make Safe brief

Everything public data says about one Make Safe SR, or every SR on a workbook tab: corners, ramps, ramp program, complaint and repair history, permits, capital projects and nearby 311.

With Claude

The same Make Safe brief and lookups run as a local MCP server for Claude Desktop and Claude Code: see nyc-opendata-mcp.
